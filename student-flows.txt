------------------------------------------------------------
DESIGNING  (shared poster design system — for the student user manual)
------------------------------------------------------------
All three posters share one high-end design language so the student manual
reads as a single, consistent set.

Canvas:
  - Format : 1080 x 1080 px square (Facebook / social post)
  - Font   : Plus Jakarta Sans (400-800 weights)
  - Tool   : Tailwind CSS via Play CDN, self-contained HTML

Background:
  - Base   : linear-gradient(135deg, #ffffff -> #eff6ff -> #bfdbfe -> #93c5fd)
  - Glows  : soft brand-blue radial blurs (top-right, bottom-left)
  - Lines  : faint diagonal line grid (repeating-linear-gradient) faded with a
             radial mask so it dissolves toward the edges
  - Texture: subtle dot grid (radial-gradient #cbd5e1, 32px)

Header (every poster):
  - Logo   : rounded-2xl brand-gradient chip with Liberalis logo (poster-logo.png)
  - Wordmark: LIBER + ALIS (brand-600) + "Official" pill
  - Subline : "Student Government Management System" (uppercase, tracking-wide)

Color tokens (from apps/web globals.css):
  brand.50-900  : #eff6ff ... #1e3a8a   (primary blue scale)
  brand-gradient: linear-gradient(135deg, #2563eb, #1e40af)
  textStrong #111827 | textSubtle #374151 | textMuted #6b7280 | textFaint #9ca3af
  status green #16a34a | amber #d97706 | red #dc2626

Reusable components:
  - Badge pill      : brand-50 bg, brand-200 border, brand-700 text
  - Card surface     : white bg, #e5e7eb border, soft shadow
  - Step / reminder cards: number in brand-gradient circle + bold title + sub text
  - macOS browser frame : 14px radius, 3 traffic-light dots
                      (#ff5f57 / #febc2e / #28c840) + address bar
  - Buttons         : brand-gradient, white text, brand-600 shadow
  - Footer          : brand-600 dot + "Official Student Portal Gateway" +
                     portal URL + support line, separated by top border

Consistency rules for new posters:
  - Keep the 1080x1080 canvas and the white->blue gradient base.
  - Always show the Liberalis logo + wordmark in the header.
  - Use only brand / neutral / status tokens above — never off-palette colors.
  - Reuse the card, badge, step-card and macOS-frame components as-is.
  - End every poster with the same footer (URL = the page the poster describes).
