Ops Reference · Case Lifecycle

RESCUE REPORT WORKFLOW

Live Process
RESIDENT ADMIN RESCUER REASSIGN PATH

01 · Submit Report

RESIDENT

Resident files an incident report describing the emergency and location. Case enters the queue with status PENDING.

02 · Verify Report

ADMIN

Admin reviews the submitted case for legitimacy and completeness before it can move forward. Status set to VERIFIED.

03 · Assign Rescuer

ADMIN

Admin dispatches the case to an available rescuer. Status set to ASSIGNED, awaiting rescuer response.

04 · Rescuer Response

RESCUER

Rescuer must accept or decline the assigned case.

✓ Accepted

Proceeds to Step 05 — case goes in progress.

✕ Not Accepted

Returns to Admin to reassign a different rescuer — loops back to Step 03.

↺ loop to Step 03 · Assign Rescuer

05 · Rescue In Progress

RESCUER

Once accepted, case status changes to IN PROGRESS and the rescuer proceeds to the site.

06 · Attach Proof of Rescue

RESCUER

Rescuer uploads photo/file evidence of the rescue, which notifies Admin that the operation is underway or done.

07 · Resolve Case

ADMIN

Admin reviews the attached evidence and marks the case RESOLVED, closing the report.

PENDING → VERIFIED → ASSIGNED → IN PROGRESS → RESOLVED
